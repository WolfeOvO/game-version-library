## 数据口径

版本原文、规范化版本、渠道和发布日期按来源保留。下载入口跳转到上游；访问状态不等于对文件内容的独立安全背书。

数据 Schema、采集器和网站构建配置均见 [GitHub 开源仓库](https://github.com/WolfeOvO/game-version-library)。
