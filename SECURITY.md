# Security Policy

The public scope is non-Minecraft game libraries only. Do not submit Minecraft source or snapshots here.

Do not submit:

- API keys, access tokens, cookies or account credentials;
- temporary signed URLs or URLs whose validity depends on a private session;
- private source snapshots or unpublished personal data;
- game archives or installer binaries.

Report a suspected credential leak privately to the repository owner rather than opening a public issue.
